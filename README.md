# Movie-Database-Assistant
A multi-user movie database application built with Python and SQLite that allows users to manage personal movie collections using data from an external API. The project features an integrated AI chat assistant for real-time movie recommendations, answering queries, and guiding users through the application. It also generates a dynamic HTML website to visually display each user's movie library with posters, ratings, and trailer links.
